# Code of Conduct

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, religion or sexual orientation.

## Expected behaviour

- Be respectful and constructive.
- Accept feedback gracefully and focus on what is best for the project.
- Show empathy towards other community members.

## Unacceptable behaviour

- Harassment, insults or discriminatory comments.
- Publishing private information of others without permission.
- Any other conduct that would be inappropriate in a professional setting.

## Enforcement

The maintainers may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this code of conduct. Report incidents to the maintainers via a GitHub issue or private message.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
